# @zaimokuza/dsh-plugin-hub-catalog-demo

主市场演示目录，保留固定的公共插件 JSON 快照，另外包含演示子来源插件。只更新 `plugins.json` 即可独立发布；不在构建或用户侧扫描 GitHub。

Main demo catalog: a fixed public JSON snapshot plus the demo source plugin. Update plugins.json and publish independently; builds and clients do not scan GitHub.

说明与示例 / Guide: https://github.com/zaimokuza-yoshiteru/dsh-plugin-hub#readme

目录中的第三方插件不等于经过运行验证。 / Catalog inclusion does not mean third-party plugins were runtime-tested.
